# Android TV scrolling and focus audit

Source audit for this branch (not an emulator/D-pad runtime test). Changes are guarded by `DeviceUtils.isTv` where a phone layout existed; touch layouts retain their previous containers and interactions. The common TV poster-grid column policy is six columns and overscan padding is 24dp horizontally / 32dp below.

| Screen checked | Original risk | Result |
| --- | --- | --- |
| Favorites | Header and tabs outside the grid; groups in a separate Card; cards in a height-limited nested Card grid. | TV-only single keyed `LazyVerticalGrid` with one saved state. Header, tabs, group selector, empty action and `${type}:${id}` cards are all full-span/regular items. Focus links sidebar, tabs, group, cards; card MENU/long-OK and modal actions restore card/neighbor focus; deletion/clearing/group removal restore actionable targets. Saved playlist selection and a TV-only initial-load barrier protect the grid's restored scroll position. Phone path unchanged. |
| Last Watched | Unfinished/finished headings were already in a keyed `LazyColumn`, but title/tabs were outside; no hoisted state or deletion-focus recovery. | TV-only keyed `LazyColumn` now contains title/tabs, clear action, section headings and records. Hoisted `LazyListState` survives tab changes; switching back reveals the tab control so focus is never requested on an offscreen item. Row keys track episode identity. Removed/cleared rows restore focus to a surviving row or browse action. Phone path unchanged. |
| Movies | App header, home banner and genre/filter controls outside the results grid, leaving less TV viewport. | TV-only shared keyed poster grid contains them and movies. Pull-to-refresh / existing phone grid remain unchanged. |
| Series | App header and genre/filter controls outside the series grid. | TV-only shared keyed poster grid contains both and keyed series. Series copy-title behavior untouched. |
| Country/genre results | Country title, filter, sort status outside poster grid. | TV-only shared keyed grid contains back/filter/sort controls and keyed mixed movie/series results. Phone path unchanged. |
| Search | Title, native TV search field and country stories above a separately scrolling results grid. | TV-only keyed grid contains controls, stories, loading/empty/retry and results. Native TV `EditText` remains the IME target; phone path unchanged. |
| Live TV | Browse chips, native TV search, category chips and channel results in separate vertical areas. | TV-only keyed grid contains them; channel cards bring focus into view with the same thin frame, 6-column sizing and overscan padding. Picker dialog still has its own bounded, keyed `LazyColumn` by design; it is not a nested full-screen content viewport. Phone path unchanged. |
| Settings hub | Already a single `LazyColumn` with its header inside and no nested fixed-height result viewport. | Keyed header/cards, TV bottom inset and focused-row bring-into-view; phone inset unchanged. Subpages use a persistent back/title toolbar plus one vertical scroll container (`LazyColumn` or `verticalScroll`); the font picker uses the existing body scroll and focused rows bring themselves fully into view. Theme settings now keys its lazy sections, options and swatch rows. |

The source audit does not prove remote focus order or phone appearance on hardware. CI compilation and JVM tests are separate checks; an emulator/TV or keyboard D-pad session is still needed for device verification.
